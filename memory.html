Политика конфиденциальности

RunTimer — это личный таймер для тренировок. Приложение не собирает и не передаёт никакие личные данные.

Хранение настроек. Ваши настройки хранятся локально в вашем браузере (localStorage) и никуда не отправляются.

Отсутствие трекеров и рекламы. Приложение не использует сторонние аналитику, трекеры и рекламу.

Сторонние сервисы. Приложение размещено на GitHub Pages (GitHub Inc.).
