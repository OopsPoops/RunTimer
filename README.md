# 🏃 RunTimer

Интервальный таймер для бега с голосовыми подсказками, а также силовые тренировки и мини-игры. Настраивается под расписание, есть готовые шаблоны на 8 недель.

## 🌐 Сайт

**Открыть приложение: <a href="https://oopspoops.github.io/RunTimer/" target="_blank" rel="noopener">https://oopspoops.github.io/RunTimer/</a>**

> 💡 На iPhone: откройте ссылку в Safari → «Поделиться» → «На экран “Домой”» — приложение появится на главном экране с иконкой и будет работать в полноэкранном режиме.

Просто откройте сайт — это статические HTML-страницы на GitHub Pages, сервер не нужен.

## 🗂️ Страницы

- **Главная / Бег** — интервальный таймер этапов (бег / ходьба) с голосовым озвучиванием и шаблонами тренировок
- **Силовая** — упражнения по расписанию
- **Игры** (в папке `game/`)
  - **Найди пару** — карточная игра на память
  - **2048** — классическая головоломка
  - **Раннер** — бегунок с прыжками от препятствий
  - **Три в ряд** — головоломка «три в ряд» на спортивных смайлах
  - **Gravity Defied** — мотокросс-гонка (веб-порт игры yurkagon, лицензия GPL-2.0, исходники: github.com/yurkagon/gravity-defied-web)

## ✨ Возможности

- ⏱️ Таймер этапов (бег / ходьба) с голосовым озвучиванием
- 🔊 Голосовые команды этапов («Бежим!», «Идём», «Быстрым шагом») — озвучка играет поверх музыки и не ставит её на паузу
- 🔔 Лёгкое мигание таймера и звуковой сигнал при смене этапа
- ⚙️ Сворачиваемые настройки: время этапов задаётся в секундах
- 📋 **Шаблоны**: 24 готовые тренировки по расписанию (8 недель × Пн/Чт/Сб) — по нажатию подставляются бег/ходьба/подходы. Кнопки **+/−** слева от строки дублируют/удаляют копии недели
- 💾 Настройки и рекорды игр запоминаются в браузере между визитами
- 🔋 Wake Lock — экран не гаснет во время тренировки. ⚠️ Держите экран включённым: на заблокированном экране iOS приостанавливает сайт, и озвучка/таймер не идут

## 🛠️ Для разработки

Репозиторий содержит:

- `index.html` — главная: таймер бега и шаблоны
- `sila.html` — силовая тренировка
- `style.css` — общие стили (темы, навигация)
- `icon.png` — иконка для главного экрана iPhone
- `voice/` — записанные голосовые подсказки (озвучка этапов)
- `game/` — все игры:
  - `game_2048.html` — 2048
  - `game_memory.html` — «Найди пару»
  - `game_runner.html` — раннер (ассеты `runner_*.png` рядом)
  - `game_match3.html` — «Три в ряд»
  - `gravity/` — Gravity Defied (собрана из репозитория yurkagon/gravity-defied-web, лицензия GPL-2.0)

Любые изменения в `main` автоматически разворачиваются на GitHub Pages.
