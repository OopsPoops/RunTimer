# 🏃 RunTimer

Интервальный таймер для бега с голосовыми подсказками. Настраивается под расписание, есть готовые шаблоны на 8 недель.

## 🌐 Сайт

**Открыть приложение: [https://oopspoops.github.io/RunTimer/](https://oopspoops.github.io/RunTimer/)**

> 💡 На iPhone: откройте ссылку в Safari → «Поделиться» → «На экран “Домой”» — приложение появится на главном экране с иконкой и будет работать в полноэкранном режиме.

## ✨ Возможности

- ⏱️ Таймер этапов (бег / ходьба) с голосовым озвучиванием
- 🔊 Голосовые команды этапов («Бежим!», «Идём», «Быстрым шагом»)
- 🔔 Лёгкое мигание таймера и звуковой сигнал при смене этапа
- ⚙️ Сворачиваемые настройки: время этапов задаётся в секундах
- 📋 **Шаблоны**: 24 готовые тренировки по расписанию (8 недель × Пн/Чт/Сб) — по нажатию подставляются бег/ходьба/подходы
- 💾 Настройки запоминаются в браузере между визитами
- 🔋 Wake Lock — экран не гаснет во время тренировки. ⚠️ Держите экран включённым: на заблокированном экране iOS приостанавливает сайт, и озвучка/таймер не идут

## 🚀 Запуск

Просто откройте сайт. Это один самодостаточный HTML-файл — сервер не нужен.

## 🛠️ Для разработки

Репозиторий содержит:

- `index.html` — всё приложение (HTML + CSS + JS)
- `icon.png` — иконка для главного экрана iPhone

Любые изменения в `main` автоматически разворачиваются на GitHub Pages.
