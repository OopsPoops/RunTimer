Политика конфиденциальности

RunTimer — это личный таймер для тренировок. Приложение не собирает и не передаёт никакие личные данные.

Хранение настроек. Ваши настройки (время этапов, выбранные шаблоны) хранятся локально в вашем браузере (localStorage) и никуда не отправляются. Очистка данных сайта в браузере удалит их.

Отсутствие трекеров и рекламы. Приложение не использует сторонние аналитику, трекеры и рекламу.

Звук и озвучка. Для голосовых подсказок и звуковых сигналов используются стандартные возможности браузера (SpeechSynthesis, Web Audio). Данные не передаются на сервер.

Сторонние сервисы. Приложение размещено на GitHub Pages (GitHub Inc.), который обрабатывает сетевые запросы в соответствии со своей политикой конфиденциальности.

Контакты. По вопросам, связанным с политикой конфиденциальности, пишите на avalarionov@gmail.com.
